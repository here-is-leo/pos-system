POS-System documentation

A point-of-sale and inventory platform split into four independent applications — a shared backend, an admin console, a till for sales staff, and a console for the warehouse. This page covers architecture, roles, setup, and the data rules that hold it together.

01

The four applications

:5000

Handles every API call, authentication, and database read/write. Nothing else in the system talks to the database directly.

pos-backend/
:8080

rtl-admin-dashboard/
:3000

Sales System

invoice-management-system/
:3001

Warehouse System

04

Core features

Products & inventory

  • Optional unique product code, barcode support
  • Units: bottle, carton, liter — carton quantity configurable
  • Unit and carton pricing auto-calculated
  • Stock minimums and in/out-of-stock status

Customers & settlements

  • Purchase history and running statistics
  • Debt calculation and partial-payment settlement
  • Payment history per customer

Invoicing

  • Customer search or on-the-fly creation
  • Item and total discounts
  • Draft watermark for regular sellers, printed with product codes

Reporting

  • Sales by day, week, month
  • Top 5 customers, seller commission at 4%
  • Excel and PDF export

08

Stack & security

Technology

  • Node.js + Express, SQLite via Prisma
  • React + Vite + TanStack Router, Next.js 16 (×2)
  • Tailwind CSS + shadcn/ui, Recharts, XLSX, jsPDF

Security

  • JWT auth, 7-day expiry · bcrypt password hashing
  • Rate limiting, captcha after 3 failed attempts
  • Role-based access, CORS restricted to allowed domains

مستندات سیستم POS

یک پلتفرم فروش و مدیریت موجودی که به چهار اپلیکیشن مستقل تقسیم شده است: یک بک‌اند مشترک، یک پنل مدیریت، یک صندوق برای فروشندگان، و یک کنسول برای انباردار. این صفحه معماری، نقش‌ها، نصب، و قوانین داده‌ای را که همه را کنار هم نگه می‌دارد پوشش می‌دهد.

قابلیت‌های اصلی

محصولات و موجودی

  • کد کالای یکتا (اختیاری)، پشتیبانی از بارکد
  • واحدها: بطری، کارتن، لیتر — تعداد در کارتن قابل تنظیم
  • قیمت واحد و کارتن به‌صورت خودکار محاسبه می‌شود
  • حداقل موجودی و وضعیت موجود/ناموجود

مشتریان و تسویه‌حساب

  • تاریخچه خرید و آمار لحظه‌ای
  • محاسبه بدهی و تسویه با پرداخت جزئی
  • تاریخچه پرداخت برای هر مشتری

صدور فاکتور

  • جستجوی مشتری یا ایجاد در لحظه
  • تخفیف آیتمی و کلی
  • واترمارک پیش‌نویس برای فروشندگان عادی، چاپ با کد کالا

گزارش‌گیری

  • فروش روزانه، هفتگی، ماهانه
  • ۵ مشتری برتر، کمیسیون فروشنده ۴٪
  • خروجی Excel و PDF

فناوری و امنیت

فناوری

  • Node.js + Express، SQLite از طریق Prisma
  • React + Vite + TanStack Router، دو Next.js 16
  • Tailwind CSS + shadcn/ui، Recharts، XLSX، jsPDF

امنیت

  • احراز هویت JWT با انقضای ۷ روز · هش رمز با bcrypt
  • محدودیت نرخ درخواست، کپچا پس از ۳ تلاش ناموفق
  • دسترسی مبتنی بر نقش، محدودیت CORS به دامنه‌های مجاز
